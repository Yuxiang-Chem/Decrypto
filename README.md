# Decrypto（中文）

四名玩家各用一部手机。无需账户。三个主页面：本轮游戏、对手记录、我方记录。

## 使用

创建房间，复制房间链接邀请其他三人。各队两人。大厅阶段不显示词语；四人选好队伍后由房主开始游戏，进入选词阶段，各队可替换一个词或全部四词，四人都锁定词语后开始第一轮。开始前可与对方队玩家交换位置，或由系统随机重组队伍；每次换队后双方重新抽词并取消准备，防止换队者知道对手词语。

A、B 两队轮流出题，每轮交换出题人。出题人按私密密码顺序提交三条线索；指定对手玩家与队友同时猜测，双方都提交后统一揭晓，线索自动按正确编号归档。第一轮跳过截获。房主可在大厅设置猜测限时（默认不限时）；提交线索后双方共享倒计时，到时未提交按猜错处理，已提交答案保留。出线索可独立设置相同的限时选项，默认不限时；输入自动保存，超时自动提交已填写线索（空白保留），双方继续猜测。加赛不限时。两队都完成本轮后自动结算，无需点击结算按钮。只有一队触发获胜条件时获胜；双方同轮触发时进入秘密词加赛，提供对手四个词的字数提示。最多八轮，无人触发时比较净得分，平分则加赛。

服务器会拒绝越权及过期操作。非出题人的响应不包含未揭晓密码；对手的猜测不发给作答方。D1 保存房间状态，用版本号比较更新处理同时提交。随机匿名身份保存在 HttpOnly Cookie 中，数据库仅保存身份哈希。浏览器只保存最近房间号，不保存权威游戏进度。

右上角可退出房间：大厅中退出会空出座位（房主离开则由下一位接任）；游戏中退出会中止本局，其余玩家回到大厅。所有人退出后删除房间数据；超过 7 天无操作的房间会在有人创建新房间时清理。同一浏览器的多个标签页属于同一玩家；测试多人请使用不同浏览器配置或设备。刷新能恢复座位；清除 Cookie 会丢失座位。请只将邀请链接交给一起玩的朋友。房间最多四人。

## 开发

- `npm ci` 安装锁定依赖。
- `npm run dev` 本地预览。
- `npm run build` 构建 Cloudflare Worker。
- `npm run db:generate` 在更改 `db/schema.ts` 后生成迁移。
- 按 Sites 工作流应用 `drizzle/` 迁移；不要在请求处理时建立表。
- `npx tsc --noEmit` 检查类型。
- Node 24：`node --experimental-transform-types --test tests/engine.test.ts`。
- 运行本地服务器并应用迁移后：`node tests/http.mjs`。仅对本地测试环境运行；测试会创建独立房间。

## 部署

正式地址：https://game.chemisgreat.online 。`npx wrangler login` 后运行 `npm run deploy`：构建、对 Cloudflare D1 数据库 `decrypto-cn` 应用 `drizzle/` 迁移，并把 Worker `decrypto-cn` 部署到自定义域名。浏览器每约 1.8 秒同步状态，隐藏标签页暂停同步。

词库为自编中文词库，并非商业桌游卡牌数据。规则自动判断精确密码；线索的语义合规由玩家自行遵守。加赛秘密词采用规范化后的文字精确匹配，不作同义词判断。
